Инициализация всех плагнов происходит только тут app/main.js

Правило для ИИ и автоматических агентов: App.js нельзя редактировать вручную. Это сгенерированный файл, который собирается gulp-ом из исходников в папке app. Все изменения нужно вносить в соответствующие файлы app/**, после чего запускать gulp js для пересборки App.js.
